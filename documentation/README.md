# Projekt-Dokumentation:

## Was ich gemacht habe

- Ich habe mir einen GitHub Account erstellt: https://github.com/sharp-confusion
- dann habe ich ein neues öffentliches Projekt `informatik-projekt-2026` erstellt. So kann jeder den Code sehen und ich kann den Code Zuhause und in der Schule direkt online bearbeiten
- Ich habe eine Website mit mehreren HTML-Seiten erstellt.
  - Jede Seite befindet sich im Ordner `docs/`.
  - Die Navigation verbindet die Seiten miteinander.
  - Für das Design habe ich die CSS-Datei `docs/style.css` erstellt, damit die Formatierung auf allen Seiten gleich aussieht.
    - `index.html`: Startseite mit Informationen zur Website, einer Tabelle zu den verschiedenen gamemodes und was ein click macht und listen über die gamemodes und welche geräte das spiel supporten.
    - `creator.html`: Seite über den Ersteller / das Projekt.
    - `install.html`: Installationsseite mit Steam-Preis in Euro und Link zu dem steam spiel.
    - `mods.html`: Seite zu Mods mit link zu Geode.
    - `more.html`: Weitere Infos und Links.
    - `docs/img/`: Bilder für die Website.
  - Jede Seite enthält das selbe Menü
- Ich habe für die Seite unter `Settings / Pages` GitHub Pages aktiviert. Dadurch ist der Inhalt des Ordners `docs` öffentlich unter der URL https://sharp-confusion.github.io/informatik-projekt-2026/ erreichbar.
- Ich habe die Aufgabenstellung von Onenote in Copilot kopiert und es gebeten daraus eine formatierte Markdown-Datei mit Checkboxen für die Aufgaben zu erstellen
- Ich habe Copilot gesagt, es soll sich den Ordner `docs` anschauen und die Punkte die erledigt sind abhaken
