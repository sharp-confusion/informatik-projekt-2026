# Projekt-Dokumentation:

## Was ich gemacht habe:

- Ich habe eine Website mit mehreren HTML-Seiten erstellt.
- Jede Seite befindet sich im Ordner `docs/`.
- Die Navigation verbindet die Seiten miteinander.
- Für das Design habe ich die CSS-Datei `docs/style.css` verwendet.
- `index.html`: Startseite mit Informationen zur Website.
- `creator.html`: Seite über den Ersteller / das Projekt.
- `install.html`: Installationsseite mit Steam-Preis in Euro und Link zu dem steam spiel.
- `mods.html`: Seite zu Mods mit link zu Geode.
- `more.html`: Weitere Infos und Links.
- `docs/img/`: Bilder für die Website.
- In der ersten README habe ich die Aufgabenstellung von Onenote kopiert

Ich habe das Projekt als öffentliches GitHub-Repository angelegt und alle Dateien in `docs/` hochgeladen.
Danach habe ich GitHub Pages aktiviert, damit die Website online erreichbar ist.
So kann man den Code sehen und die Seite direkt im Browser öffnen.


- Die Website ist lokal im Browser lauffähig.
- Alle Links sind intern oder extern korrekt verlinkt.
- Die Seite verwendet HTML-Struktur, CSS und Bilder.
